# Apocalypse Food Prep — Power BI Dashboard

## Project Overview
This is my first Power BI dashboard, created as part of my journey in learning data science and data visualization.

The project explores food product prices across different stores and products using Microsoft Power BI.

## Dashboard Features
- **KPI Cards:** Average Price, Total Recorded Price, and Product Count.
- **Price Analysis:** Compares average product prices across stores and products.
- **Time Trend:** Examines average recorded prices over time.
- **Interactive Filters:** Uses Store and Product slicers to explore the data.

## Tools Used
- Microsoft Power BI
- Power Query for data preparation, where applicable
- DAX for creating measures

## Dataset
The project uses the Apocalypse Food Prep dataset sourced from Alex the Analyst's Power BI resources. The analysis focuses on recorded product prices.

## What I Learned
- Creating KPI cards and visualizations.
- Comparing product prices across stores.
- Exploring price trends over time.
- Building an interactive dashboard with slicers.
- Formatting visuals to improve readability.

Completed as my first Power BI practice project. I look forward to learning more and building additional data analytics projects.
